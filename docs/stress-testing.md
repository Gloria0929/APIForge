# 场景压力测试工作台

入口：场景详情 → 压力测试。

## 操作

- 测试配置：快速验证 / 常规负载 / 容量摸底预设；可调整虚拟用户数、固定时长或固定场景轮次、爬升时长、步间延迟、失败率停止阈值和请求超时。配置按项目与场景保存在当前浏览器。
- 负载预览：显示计划的用户爬升曲线。固定轮次的基础请求量为步骤数 × 场景轮次；循环步骤会增加实际请求量。
- 实时监控：最近采样区间 RPS、失败率、平均响应时间、P95、完成轮次和活跃用户数；图表支持吞吐、响应时间、用户数切换及悬停查看。
- 停止与恢复：停止按钮向后台 Locust 进程发送停止信号，保留已经采集到的结果。收起工作台不会停止任务，浮窗可重新打开工作台。刷新页面会恢复后台任务，短暂断网会重连，不会重复启动。
- 结果与历史：结果不会自动关闭。支持日志搜索、仅看错误、复制日志、导出 JSON 指标、查看报告、复用历史配置和选择两份报告进行性能对比。

爬升时间属于总运行时间，详见 [Locust 的运行时长说明](https://docs.locust.io/en/stable/running-without-web-ui.html)。失败率保护在至少 10 个请求后生效；0 表示关闭该保护。固定轮次模式最长运行 30 分钟，达到上限会明确标记为停止。

## 检查与修复

1. 固定轮次原来在启动最后一轮后就退出，慢的并发场景可能被截断。现在区分已启动与已完成轮次，等待所有目标轮次完整结束。
2. 运行中的浮窗原来可清除前端任务，但不会结束后台负载。现在分别提供收起和主动停止，后台也拒绝重复启动。
3. 前端原来在刷新后丢失任务、结束后自动清空结果。现在恢复任务并保留结果，报告继续写入现有数据库。
4. 原实时 RPS 是累计平均值，历史图里的平均响应时间实际读取了中位数。现在 RPS 按相邻采样差值计算，平均值读取对应 CSV 字段，并保留吞吐小数。
5. 每个场景轮次重置运行变量，避免上次提取值掩盖本轮提取失败；失败率 0 不再误触发停止。
6. 检查空场景、执行模式、负载参数范围，以及场景、环境、测试用例是否属于同一项目。

## 验证

```sh
npm test
npm run test:ui
node tests/stress-ui.cjs
cd frontend && npm run build
```

Locust 引擎集成测试仅访问临时启动的本地 HTTP 服务，不调用项目环境。使用安装了 Locust 2.47.0 的 Python 运行：

```sh
python3 tests/locust-runner.test.py
```

测试覆盖并发慢请求完整轮次、失败阈值、零阈值、变量跨轮次隔离和固定时长轮次统计。另已实际验证 Node 适配器发送 SIGINT 后 Locust 退出并返回部分指标。

## 持久化范围

刷新浏览器可以恢复任务；后台进程重启后，内存中的活动任务无法继续恢复。已生成报告保存在原数据库中。工作台历史按场景 ID 筛选，升级前未记录场景 ID 的压测报告仍可从测试报告列表查看。
